# 罗马斗兽场 · 公元八十年（Three.js 1:1 复原）

用 Three.js 程序化重建的罗马斗兽场（弗拉维圆形剧场）。场景按原尺寸建模，复原的是提图斯落成庆典前后（公元 80–90 年）的完整状态。现场有五万观众，节目单上有开场游行、斗兽、午间余兴、角斗士对决和海战表演，并配语音导览。所有建筑、人物、动物、纹理和音效都由代码生成，不依赖外部模型、图片或音效文件。

- **1:1 尺寸**：外轮廓 188 × 156 m，竞技场约 83 × 48 m，外墙高 48.4 m，四层分别为 10.50、11.85、11.60、14.45 m。80 个开间按外墙弧长等分，开间宽约 6.77 m。
- **外立面**：从下到上依次是托斯卡纳、爱奥尼、科林斯半柱和科林斯壁柱阁楼层（叠柱式）。底层 76 座门洞刻有罗马数字 I–LXXVI，四个轴线门不编号，南北两门带门廊。二、三层每个拱门里立一尊雕像。阁楼层隔间开方窗、挂青铜圆盾，墙上有 240 个托座承托桅杆。
- **结构**：外环有两圈带筒拱的回廊、内环墩柱和内墙，楼面三层。
- **看台**：自下而上为讲台层元老席（大理石宽台阶、护墙、防护网与网杆）、第一区骑士席、第二区平民席上下两区、顶层木座，最高处是一圈柱廊。看台上有出入口（沃米托里亚）和放射状楼梯。南侧是皇帝包厢，北侧是主办官包厢。
- **竞技场与地下室**：竞技场铺沙的木地板可揭开北半部，露出两层通道的地下室，包括兽笼、28 部升降机（活板门、升降平台、绞盘和推绞盘的工人）以及中央布景升降台。东西长轴两端的大门与隧道相通。
- **遮阳天篷**：240 根桅杆和放射状绳索撑起中央椭圆绳环，帆布可动画收放，并在看台上投下阴影。
- **周边**：广场铺地与 80 块界石，汗水泉，尼禄巨像（太阳神像），大角斗士学校（院内有椭圆训练场），神君克劳狄神庙台地，提图斯浴场，帕拉蒂尼、西里欧、奥皮奥诸山，远处民居和石松、柏树。
- **观众**：约 3.4 万个实例化坐像，按座次法分区着装。观众在着色器里实时起身欢呼、挥手，会朝场上的事件方向起哄。

## 节目（比赛项目）

| 节目 | 内容 |
|---|---|
| 开场游行 | 束棒侍从、长直号与弯号乐手、主办官和披斗篷的角斗士从凯旋之门入场，绕场后向皇帝包厢致敬并当众验剑 |
| 斗兽表演 | 中央升降台升起假山树丛，狮、母狮、豹、虎、熊、公牛、鸵鸟从各升降机冒出，大象从死亡之门进场；猎兽手步行或骑马追逐，还有熊斗公牛 |
| 午间余兴 | 滑稽打斗、杂技（倒立、抛接）、藏红花香雾喷洒、向看台抛撒奖券 |
| 角斗士对决 | 五种经典配对：鱼网斗士对追击斗士（会撒网缠人）、色雷斯斗士对鱼盔斗士、重装斗士对鱼盔斗士、挑战斗士对挑战斗士、骑马斗士对骑马斗士（先策马对冲，再下马步战）。场上有裁判和乐队（含水力风琴）；落败者举指求饶，全场呼喊，获赦后胜者领棕榈枝 |
| 海战表演 | 竞技场注水，两支舰队各三艘战船划桨对冲、撞角相撞，战败的船会下沉 |
| 全天连播 | 按真实节目顺序，从开场游行一路演到角斗 |

各套装备都按兵种区分：鱼盔斗士戴鱼鳍冠头盔、持长方大盾；色雷斯斗士用弯刀、小方盾，戴狮鹫冠头盔，双腿套高护胫；追击斗士戴光滑蛋形头盔；鱼网斗士不戴头盔，用渔网和三叉戟，左肩有护肩；其余兵种依此类推。现场音效由 WebAudio 实时合成，包括人群底噪与欢呼、号角、水力风琴、兵器撞击、猛兽吼叫、大象长鸣和水声。讲解播放时，现场音效自动压低。

## 语音导览（参照故宫项目）

- 共 44 段讲解词，约 7000 字，覆盖建筑、座次、周边地标、节目和各兵种。
- 全部用 F5-TTS 配音，音色与故宫项目相同（人工老龙凤），总长约 23 分钟。质检全部通过：回听拼音吻合度最低 0.94、中位 0.99，响度一致，没有截断。
- **点击任意建筑部位或场上人物、动物**，都会弹出讲解卡并自动播放，讲解时逐句高亮，可以暂停和拖动进度。
- **导览漫游**：按 24 站逐一飞行讲解，到达地下室一站时会自动揭开地板。
- 节目进行中会按进度自动讲解，例如角斗开始先讲两个兵种，求饶时讲“胜负与赦免”。

## 运行

```bash
npm install
npm run dev
```

用浏览器打开终端里显示的地址，建议使用独立显卡。

| 地址参数 | 作用 |
|---|---|
| `?view=arena` | 打开时的视角，可选值见 `src/ui/views.js` |
| `?ao=1` | 开启环境光遮蔽（GTAO） |
| `?lite=1` | 观众密度减半（低性能设备） |
| `?hypo=1` | 打开时揭开地板 |
| `?furl=1` / `?velum=0` | 收起或隐藏天篷 |

## 操作

- 左键旋转，右键平移，滚轮缩放。点击建筑或人物播放讲解，Esc 停止。
- 左侧面板：
  - 寻找讲解：搜索讲解条目
  - 节目单：五个节目和五种角斗配对
  - **入座观赛**：皇帝包厢、元老席、骑士席、平民席、顶层木座，可以感受不同阶层的视角
  - 视角预设、导览漫游、漫步模式（WASD）、环绕
  - 显示选项：天篷收放、揭开地板、观众、标签、节目讲解、音效与音量、环境光遮蔽
  - 时辰：按罗马的十二时辰调整日照
- 节目进行时，顶部横幅显示当前节目，可以停止节目或关闭“跟随镜头”。
- 右上角小地图可以点击跳转。

## 讲解词与配音

讲解词放在 `src/data/guide/*.json`，字段为 `name`、`aliases`、`sub`、`text`。配音清单是 `src/data/guide/audio.json`，音频在 `public/audio/guide/`。脚本沿用故宫项目，用的是 `123_AI视频自动化` 的 F5 环境。朗读稿里的多音字会自动替换，例如“角斗”读作“决斗”，“长矛”读作“常矛”。

```bash
"F:\我的编程项目\123_AI视频自动化\tools\f5-tts-env\python.exe" scripts/guide_tts.py   # 只重录改动过的条目
"F:\我的编程项目\123_AI视频自动化\tools\f5-tts-env\python.exe" scripts/audio_qc.py    # 质检：回听、响度、停顿、截断、语速
```

## 目录结构

```
src/config.js            尺寸常量（外轮廓、竞技场、各层标高）
src/core/                椭圆几何与“弯曲贴合”、几何工具、程序化纹理、材质、渲染环境、合并器
src/model/orders.js      柱式构件：托斯卡纳/爱奥尼/科林斯半柱、壁柱、基座、雕像、圆盾、托座
src/model/facade.js      外立面四层 + 外环回廊
src/model/cavea.js       看台各区、出入口、楼梯、包厢、顶层柱廊
src/model/arena.js       竞技场地板、活板门、升降机、地下室、大门隧道、防护网、水面
src/model/velarium.js    天篷
src/model/surroundings.js 地形与周边建筑
src/actors/              可动人物（各兵种装备）、动物、观众、节目导演
src/ui/                  界面、讲解卡、视角与导览路线、WebAudio 音效
scripts/                 截图自检、讲解配音、配音质检
```

架构说明见 `docs/ARCHITECTURE.md`。

## 史实说明

- 皇帝包厢的位置按通行说法放在短轴南端（康茂德通道所在一侧）。凯旋之门放在长轴西端，死亡之门放在长轴东端。不同资料对东西两门的朝向说法不一。
- 斗兽场里的海战只见于开幕庆典的记载，而且只可能发生在图密善修建地下室之前。这里为了展示把两者并存，讲解中已作说明。
- 午间处决罪犯的史实只在讲解中如实提及，场景里只表演余兴节目。斗兽表演也只表现追逐与搏斗，不表现杀戮。
- 拱门雕像、阁楼层圆盾的样式，以及天篷的具体构造，学界都有不同复原方案。这里取常见的一种。
